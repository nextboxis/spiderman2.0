# 🕷️ SPIDER-MAN // Across The Multiverse

A cinematic, production-grade Spider-Man Multiverse landing page built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, **GSAP ScrollTrigger**, **Three.js (@react-three/fiber + @react-three/drei)**, **Lenis**, and **Web Audio API**.

Showcasing **Peter Parker (Earth-616)**, **Miles Morales (Earth-1610)**, **Miguel O'Hara (Earth-928)**, **Hobie Brown / Spider-Punk (Earth-138)**, and **Spider-Man Noir (Earth-90214)**.

---

## 🌟 Key Features

1. **🕸️ Web-Shooter Calibration Preloader**:
   - High-precision pressure gauge accelerating from 0 to 300 PSI.
   - Spider-Man chest emblem snap with synthetic Web Audio API "THWIP!" and Spider-Sense chime.
   - Upward web-zip transition unveiling the Manhattan skyline.

2. **🏙️ 3D Manhattan Skyline & Web of Destiny (Hero)**:
   - Three.js WebGL skyline featuring low-poly skyscrapers, illuminated windows, and dual high-tensile white web strands.
   - Character Quick-Switcher Bar: switch between Peter Parker, Miles Morales, Miguel O'Hara (2099), and Spider-Punk with dynamic quotes, colors, and telemetry.
   - "BE GREATER. TOGETHER." display typography with letter-by-letter spring physics.

3. **📜 Spider-Man Axioms & Creed (Manifesto)**:
   - Pinned scrubbed scroll tracking the eternal vows: *"With Great Power Comes Great Responsibility"*, *"Anyone Can Wear The Mask"*, and *"No Matter How Many Times We Get Hit, We Always Get Back Up"*.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router) + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Spider-Man Theme Tokens (`--color-spider-red`, `--color-spider-blue`, `--color-miles-gold`, `--color-2099-cyan`)
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Smooth Scroll**: Lenis + GSAP ScrollTrigger
- **Motion & Interactive Physics**: Framer Motion 13 + Canvas 2D Physics Engine
- **Sound**: Web Audio API (Zero external assets, instant zero-latency playback)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server

```

Visit `http://localhost:3000` to experience the Spider-Man Multiverse landing page.
